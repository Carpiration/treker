# Задачи

Общий список задач команды: кто что делает и в каком статусе. Тёмная тема, рассчитана на узкое
(плавающее) окно на ПК и на телефон.

**Сайт:** https://carpiration.github.io/treker/ · **Android:** APK в разделе Releases.

## Возможности
- Статус задачи — одна метка («Не начато», «В процессе», «Готово»), меняется из списка.
- Подробности открываются при наведении курсора (на телефоне — касанием), редактирование — по клику.
- Профили с логином и паролем; администратор создаёт, меняет и отключает профили в настройках.
- В настройках можно скрыть, чья это задача.
- Отмена удаления и передачи задачи; управление с клавиатуры (N — новая задача, стрелки в списках, Esc).

## Режимы работы
| | Локальный | Облачный (Supabase) |
|---|---|---|
| Включается | `config.js` пустой | в `config.js` указаны URL и publishable-ключ |
| Где данные | только этот браузер | сервер, общие для всех устройств |
| Пароли | проверяются в браузере (разделение профилей, не защита) | проверяет сервер, права — правила RLS |

Настройка облака — [docs/SUPABASE.md](docs/SUPABASE.md). Размещение и обновление — [docs/DEPLOY.md](docs/DEPLOY.md).

## Запуск локально
Достаточно открыть `index.html` в браузере. Для проверки «как на сайте» — локальный сервер из корня проекта:
```
python -m http.server 8000
```
и адрес http://localhost:8000.

## Структура
```
index.html            приложение целиком (разметка, стили, логика)
config.js             подключение к Supabase (пусто — локальный режим)
manifest.webmanifest  установка на главный экран телефона
icons/                иконки
supabase/schema.sql   таблицы, правила доступа, функции администратора
android/              оболочка APK (WebView, открывает сайт), сборка: python android\build.py
docs/                 инструкции
```
Внешняя зависимость одна — `@supabase/supabase-js@2.117.3` с jsDelivr (с проверкой целостности SRI),
загружается только в облачном режиме.
