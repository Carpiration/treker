# Задачи

Общий список задач команды: кто что делает и в каком статусе. Тёмная тема, рассчитана на узкое
(плавающее) окно на ПК и на телефон.

**Сайт:** https://carpiration.github.io/treker/ · **Android:** APK в разделе Releases.

## Возможности
- **Мои задачи** — личное пространство с папками. Другие могут их смотреть (без изменения); любую папку
  и задачи без папки можно скрыть от всех, включая администратора.
- **Группы** — у каждой свои задачи и участники. Создаёт и наполняет администратор, у человека до 7 групп.
  В группе — фильтр по исполнителю со счётчиком задач.
- Статус задачи — одна метка («Не начато», «В процессе», «Готово»), меняется из списка.
- Вход по номеру телефона и PIN, ник уникален. Регистрируется любой, доступ открывает администратор.
- Меню за шестерёнкой: профиль, пользователи и заявки, группы, папки.
- Отмена удаления и передачи задачи; управление с клавиатуры (N — новая задача, стрелки в списках, Esc).

## Данные
Задачи и профили хранятся на сервере Supabase и синхронизируются между всеми устройствами в реальном времени.
PIN проверяет сервер, доступ к данным — правила RLS. Подробности — [docs/SUPABASE.md](docs/SUPABASE.md),
размещение и обновление — [docs/DEPLOY.md](docs/DEPLOY.md).

## Запуск локально
Нужен локальный сервер из корня проекта (данные — на том же сервере Supabase, что и у сайта):
```
python -m http.server 8000
```
и адрес http://localhost:8000.

## Структура
```
index.html            разметка и подключение файлов
css/app.css           стили
js/                   логика: core (общее), backend (сервер и синхронизация), spaces (группы и папки), auth (вход),
                      menu (выпадающие списки), list (список и новая задача), settings, main (запуск)
config.js             подключение к Supabase
manifest.webmanifest  установка на главный экран телефона
icons/                иконки
supabase/schema.sql   таблицы, правила доступа, функции администратора
tools/db.py           задачи из командной строки (нужен секретный ключ в .env, см. docs/SUPABASE.md)
android/              оболочка APK (WebView, открывает сайт), сборка: python android\build.py
docs/                 инструкции
```
Внешняя зависимость одна — `@supabase/supabase-js@2.117.3` с jsDelivr (с проверкой целостности SRI),
загружается при запуске.
