# Задачи

Общий список задач команды: кто что делает и в каком статусе. Тёмная тема, рассчитана на узкое
(плавающее) окно на ПК и на телефон.

**Сайт:** https://carpiration.github.io/treker/ · **Android:** APK в разделе Releases.

## Возможности
- **Мои задачи** — личное пространство с папками. Другие могут их смотреть (без изменения); любую папку
  и задачи без папки можно скрыть от всех, включая администратора.
- **Группы** — у каждой свои задачи и участники. Создаёт и наполняет администратор, у человека до 7 групп.
  В группе — фильтр по исполнителю со счётчиком задач.
- Акцентный цвет из палитры или свой; градиентный фон приложения — сила, распространение и положение
  (точку двигают на мини-экране) с предпросмотром.
- Аватарки: 10 готовых или своё фото (из галереи, с компьютера или перетаскиванием), обрезается до квадрата.
- Вид задач (меню → «Внешний вид», с предпросмотром): фон карточек лучами, обводкой или без фона;
  цвет — статус (красный, жёлтый, зелёный), смена статуса перетекает плавно, завершённая задача улетает
  в «Готовые»; лёгкое переливание; статус в строке — меткой, цветным индикатором или скрыт.
- Статус задачи — одна метка («Не начато», «В процессе», «Готово»). Переключатель «Активные / Готовые»:
  готовые по умолчанию скрыты.
- Меню задачи — правой кнопкой мыши, долгим нажатием на телефоне или Shift+F10: статус, исполнитель,
  перенос, правка, удаление.
- Описание новой задачи — тонкая полоска под названием, по нажатию раскрывается поле фиксированной высоты.
- Вход по номеру телефона и PIN, ник уникален. Регистрируется любой, доступ открывает администратор.
- **Перенос задач**: в свои папки, в группу или другому человеку (в его «Переданные» или выбранную папку).
  Администратору — только с его согласия.
- **Уведомления** (колокольчик): исполнителю — когда задачу назначили, сменили статус, удалили или передали.
  **Пуш-уведомления** на устройство (ПК, Android, iPhone с сайтом на экране «Домой») — включаются там же.
- **Журнал**: кто что когда сделал, с фильтрами по человеку, действию и месту.
- **Архив**: удалённые задачи хранятся 30 дней (видят удаливший и администратор), за сутки — предупреждение.
- Меню за шестерёнкой: профиль, пользователи и заявки, группы, папки, журнал, архив.
- Отмена удаления и передачи задачи; управление с клавиатуры (N — новая задача, стрелки в списках, Esc).

## Данные
Задачи и профили хранятся на сервере Supabase и синхронизируются между всеми устройствами в реальном времени.
PIN проверяет сервер, доступ к данным — правила RLS. Подробности — [docs/SUPABASE.md](docs/SUPABASE.md),
размещение и обновление — [docs/DEPLOY.md](docs/DEPLOY.md).

## Запуск локально
Нужен локальный сервер из корня проекта (данные — на том же сервере Supabase, что и у сайта):
```
python -m http.server 8000
```
и адрес http://localhost:8000.

## Структура
```
index.html            разметка и подключение файлов
css/app.css           стили
js/                   логика: core (общее), look (акцент и фон), push (пуши), backend (сервер и синхронизация), spaces (группы и папки), activity (уведомления, журнал, архив, перенос), auth (вход),
                      menu (выпадающие списки), list (список и новая задача), settings, main (запуск)
config.js             подключение к Supabase
manifest.webmanifest  установка на главный экран телефона
icons/                иконки приложения, avatars/ — 10 готовых аватарок
supabase/schema.sql   таблицы, правила доступа, функции
supabase/functions/push  отправка пуш-уведомлений (Edge Function, Web Push без библиотек)
sw.js                 service worker: показ пушей
tools/db.py           задачи из командной строки (нужен секретный ключ в .env, см. docs/SUPABASE.md)
android/              оболочка APK (WebView, открывает сайт), сборка: python android\build.py
docs/                 инструкции
```
Внешняя зависимость одна — `@supabase/supabase-js@2.117.3` с jsDelivr (с проверкой целостности SRI),
загружается при запуске.
