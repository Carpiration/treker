# Подключение синхронизации (Supabase)

Без этих шагов приложение работает локально: данные только в том браузере, где их ввели.
С Supabase задачи общие для всех устройств и обновляются в реальном времени. Бесплатного тарифа хватает.

## 1. Проект
1. Зарегистрируйтесь на https://supabase.com и нажмите **New project**.
2. Имя — любое (например, `treker`), регион — ближайший (Frankfurt / `eu-central-1`).
   Пароль базы данных сохраните у себя — для приложения он не нужен, никому его не пересылайте.

## 2. Отключить подтверждение e-mail
Логины хранятся как служебные адреса `логин@treker.local`, писем на них не отправляется.

**Authentication → Sign In / Providers → Email → выключить «Confirm email» → Save.**

Сделайте это до создания администратора. Регистрацию («Allow new users to sign up») оставьте включённой:
через неё администратор добавляет сотрудников. Посторонний, зарегистрировавшийся сам, получает отключённый
профиль без доступа к задачам.

## 3. Таблицы и правила доступа
**SQL Editor → New query →** вставьте целиком файл [`supabase/schema.sql`](../supabase/schema.sql) → **Run**.
Должно появиться `Success. No rows returned`. Повторный запуск безопасен.

## 4. Ключи для приложения
**Project Settings → API Keys** (или кнопка **Connect**):
- **Project URL** — вида `https://abcdefgh.supabase.co`;
- **Publishable key** (`sb_publishable_…`) или, в старом интерфейсе, **anon public**.

Эти два значения публичные по назначению — их можно прислать в чат или вписать в `config.js`.
**Секретный ключ** (`sb_secret_…` / `service_role`) никому не отправляйте и в файлы не вписывайте.

## 5. Первый запуск
После обновления `config.js` откройте сайт: появится экран **«Первый запуск»** — придумайте имя, логин и пароль
администратора. Остальных сотрудников администратор добавляет в **Настройки → Профили**.

Если на этом устройстве остались задачи из локального режима (или из Android-приложения 1.0),
в настройках администратора появится кнопка **«Перенести задачи»**.

## Если что-то пошло не так
- **«Включено подтверждение e-mail»** — выполните шаг 2, затем в SQL Editor:
  `update auth.users set email_confirmed_at = now() where email_confirmed_at is null;`
- **«Сервер не принял логин»** — Supabase отклонил служебный адрес. Поменяйте `loginDomain` в `config.js`
  (например, на `treker.example`) — только пока не создано ни одного профиля.
- **Администратор потерял пароль** — Authentication → Users → пользователь → **Send password recovery** не сработает
  (адрес служебный). Вместо этого в SQL Editor:
  `update auth.users set encrypted_password = extensions.crypt('НовыйПароль', extensions.gen_salt('bf')) where email = 'логин@treker.local';`
