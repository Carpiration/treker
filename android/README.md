# Android-приложение «Задачи»

Оболочка WebView над сайтом `APP_URL` (см. `build.py`): данные синхронизируются через сервер,
изменения сайта приходят без переустановки APK. Без сети показывается экран «Нет связи» с кнопкой «Повторить».

При первом запуске `assets/start.html` передаёт сайту задачи, сохранённые версией 1.0 внутри приложения,
— администратор переносит их в общую базу кнопкой в настройках.

## Сборка

Нужны Android SDK (build-tools, platforms/android-35) и JDK 17+ — подходит `jbr` из Android Studio. Gradle не нужен.

```
python android\build.py
```

Результат — `Treker-<версия>.apk` в корне проекта. Скрипт сам находит SDK (`ANDROID_HOME` или `%LOCALAPPDATA%\Android\Sdk`) и JDK (`JAVA_HOME` или Android Studio).

Перед выпуском новой версии увеличьте `VERSION_CODE` (и при желании `VERSION_NAME`) в `build.py`, иначе APK не установится поверх старого.

## Ключ подписи

`signing/release.jks` и `signing/keystore-password.txt` создаются при первой сборке и в репозиторий не попадают.
Храните их копию и никому не передавайте: обновления можно ставить поверх только при подписи тем же ключом.

## Установка

Скачайте APK из раздела Releases на телефоне и откройте его. Android попросит разрешить установку из этого источника.
Или через USB с включённой отладкой: `adb install -r Treker-2.0.apk`.

## Проверка

`adb logcat -s Treker` показывает сообщения и ошибки страницы.
